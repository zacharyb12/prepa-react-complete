### Navigation entre les pages

- Pour naviguer entre les pages dans une application React, nous utiliserons un routeur comme React Router.

```bash
npm install react-router-dom
```

- Cela nous permettra de définir des routes et d'associer chaque route à une page spécifique.

- Par exemple, nous pourrions avoir une route `/about` qui affiche la page `AboutPage`.

- La navigation entre les pages se fait généralement via des liens ou des boutons qui changent l'URL et injecte la page correspondante.

- Voici un exemple simple d'utilisation de React Router pour naviguer entre deux pages :

```tsx
import { BrowserRouter as Router, Route, Routes, Link } from 'react-router-dom';
import HomePage from './pages/homepage';
import AboutPage from './pages/aboutpage';

function App() {
  return (
    <Router>
      <nav>
        <Link to="/">Home</Link>
        <Link to="/about">About</Link>
      </nav>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
      </Routes>
    </Router>
  );
}

export default App;
```

- on importe les composants nécessaires de `react-router-dom`, notamment `Router`, `Route`, `Routes`.
---

### Conventions pour la navigation

- La navigation se situe généralement dans un composant `Navbar` ou `Header` qui est inclus dans le composant principal `App`.

- Les liens de navigation utilisent le composant `Link` de React Router pour changer l'URL sans recharger la page.

- Les routes sont définies dans le composant `App` ou dans un composant dédié aux routes.

- Chaque route est associée à une page spécifique via le composant `Route`.
