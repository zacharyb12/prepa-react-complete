# Les événements

### Pour gérer les événements en React, on utilise la syntaxe camelCase pour nommer les attributs des événements, et on passe une fonction en tant que gestionnaire d'événements.

- les événements sont nommés en camelCase (par exemple, `onClick`, `onChange`, etc.),

- les gestionnaires d'événements sont passés en tant que fonctions (par exemple, `onClick={handleClick}`).

Voici un exemple simple d'un bouton qui gère un événement de clic :

```tsx

function ClickButton() {

  const handleClick = () => { alert('Button clicked!'); };

  return (
    <button onClick={handleClick}> Click me </button>
  );
}
```

### Il sera possible d'ecouter les changements d'état des champs de formulaire avec l'événement `onChange`.

```tsx
function TextInput() {

  const handleChange = function(event: React.ChangeEvent<HTMLInputElement>) {

    const newValue = event.target.value;
    console.log('Valeur de input : ', newValue);
  
  }; 

  return (
    <input type="text" onChange={handleChange} />
  );

}
```

#### Notez que dans les exemples ci-dessus, nous avons défini des fonctions de gestionnaire d'événements (`handleClick` et `handleChange`) à l'intérieur du composant fonctionnel. Cela permet d'accéder facilement à l'état et aux props du composant si nécessaire.
