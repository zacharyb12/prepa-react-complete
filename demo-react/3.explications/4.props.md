# Props

- Les props (propriétés) sont des données que l'on passe aux composants pour les personnaliser.

- Les props permettent de rendre les composants réutilisables et dynamiques.

- un composant peut recevoir une ou plusieurs props sous forme d'objet.

- une prop peut avoir une valeur par defaut ce qui la rend optionnelle.

---
### Exemple de composant avec des props

```tsx
function Salutation(props : {name: string, firstname: string}) {
    return <h1>Bonjour, {props.name} {props.firstname} !</h1>;
}

export default Salutation;
```

- Utilisation du composant avec des props :

```tsx
<Salutation nom="Alice" />
```

- Cela affichera : "Bonjour, Alice!"

- Si on n'a pas besoin de passer une prop, on peut définir une valeur par défaut :

```tsx
function Salutation({name = 'Inconnu'} : {name?: string}) {
    return <h1>Bonjour, {name}!</h1>;
}
export default Salutation;

```
- Maintenant, on peut utiliser le composant sans passer de prop :

```tsx
<Salutation />
<Salutation name="Bob" />
```
