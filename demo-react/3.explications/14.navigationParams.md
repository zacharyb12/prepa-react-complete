# Navigation avec paramètres

- Pour naviguer entre les pages dans une application React, on utilise souvent des bibliothèques comme React Router.
- Parfois, il est nécessaire de passer des paramètres lors de la navigation pour afficher des informations spécifiques sur la page cible.

- On pourra dès lors fournir des paramètres dans l'URL et les récupérer dans le composant cible à l'aide des hooks fournis par React Router, comme `useParams`.

### Declaration de paramètres dans les routes
Lors de la définition des routes, on peut spécifier des paramètres dynamiques en utilisant les deux-points `:`. Par exemple :

```jsx
<Route path="/users/:id" component={UserDetail} />
```

### Redirection avec paramètres
Pour naviguer vers une route avec des paramètres, on peut utiliser le hook `useNavigate` de React Router. Voici un exemple :

```jsx
import { useNavigate } from 'react-router-dom';
const UserList = () => {
  const navigate = useNavigate();

  const goToUserDetail = (userId) => {
    navigate(`/users/${userId}`);
  };

  return (
    <div>
      <button onClick={() => goToUserDetail(1)}>Go to User 1</button>
      <button onClick={() => goToUserDetail(2)}>Go to User 2</button>
    </div>
  );
};
```

### Récupération des paramètres dans le composant cible
Dans le composant cible, on peut utiliser le hook `useParams` pour accéder aux paramètres
passés dans l'URL. Voici comment récupérer l'ID de l'utilisateur dans le composant `UserDetail` :

```jsx
import { useParams } from 'react-router-dom';
const UserDetail = () => {
  const { id } = useParams();

  return (
    <div>
      <h1>User Detail for User ID: {id}</h1>
      {/* Afficher les détails de l'utilisateur en fonction de l'ID */}
    </div>
  );
};
```

### Link ou navigate 
- Les deux permettent de naviguer entre les pages, mais `Link` est utilisé pour créer des liens dans le rendu JSX, tandis que `navigate` est une fonction qui permet de rediriger de manière programmatique en réponse à des événements ou des actions utilisateur.

- Link est souvent utilisé pour la navigation statique, tandis que navigate est plus adapté pour des scénarios dynamiques où la navigation dépend de la logique de l'application.
