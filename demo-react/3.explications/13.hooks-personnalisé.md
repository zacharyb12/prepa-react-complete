# Hooks Personnalisés

## Qu'est-ce que c'est ?

Les hooks personnalisés permettent de **réutiliser de la logique** entre plusieurs composants.
- Nom commence toujours par `use`
- Fonction JavaScript normale
- Peut utiliser d'autres hooks à l'intérieur

### Qu'est-ce qu'un hook personnalisé ?

Un hook personnalisé est une **fonction JavaScript** qui :
- Commence par le mot `use`
- Peut appeler d'autres hooks (useState, useEffect, etc.)
- Retourne des valeurs ou des fonctions utilisables dans les composants
- Permet de réutiliser de la logique entre différents composants

## Exemples simples

### 1. Hook pour un compteur

```typescript
import { useState } from 'react';

export const useCounter = (initialValue: number = 0) => {
    const [count, setCount] = useState(initialValue);

    const increment = () => setCount(count + 1);
    const decrement = () => setCount(count - 1);
    const reset = () => setCount(initialValue);

    return { count, increment, decrement, reset };
};
```

**Utilisation :**
```typescript
const MyComponent = () => {
    const { count, increment, decrement, reset } = useCounter(10);

    return (
        <div>
            <p>Compteur : {count}</p>
            <button onClick={increment}>+1</button>
            <button onClick={decrement}>-1</button>
            <button onClick={reset}>Reset</button>
        </div>
    );
};
```

### 2. Hook pour la gestion du localStorage

```typescript
import { useState, useEffect } from 'react';

export const useLocalStorage = <T>(key: string, initialValue: T) => {

    const [value, setValue] = useState<T>(() => {
        try {
            const item = localStorage.getItem(key);
            return item ? JSON.parse(item) : initialValue;
        } catch {
            return initialValue;
        }
    });

    const setStoredValue = (newValue: T) => {
        setValue(newValue);
        localStorage.setItem(key, JSON.stringify(newValue));
    };

    return [value, setStoredValue] as const;
};
```

**Utilisation :**
```typescript
const UserProfile = () => {
    const [name, setName] = useLocalStorage('userName', '');
    const [theme, setTheme] = useLocalStorage('theme', 'light');

    return (
        <div>
            <input 
                value={name} 
                onChange={(e) => setName(e.target.value)} 
                placeholder="Votre nom"
            />
            <button onClick={() => setTheme(theme === 'light' ? 'dark' : 'light')}>
                Thème : {theme}
            </button>
        </div>
    );
};
```

### 3. Hook pour les appels API

```typescript
import { useState, useEffect } from 'react';

interface UseApiState<T> {
    data: T | null;
    loading: boolean;
    error: string | null;
}

export const useApi = <T>(url: string): UseApiState<T> => {
    const [data, setData] = useState<T | null>(null);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState<string | null>(null);

    useEffect(() => {
        const fetchData = async () => {
            try {
                setLoading(true);
                setError(null);
                
                const response = await fetch(url);
                if (!response.ok) {
                    throw new Error(`Erreur: ${response.status}`);
                }
                
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err instanceof Error ? err.message : 'Erreur inconnue');
            } finally {
                setLoading(false);
            }
        };

        fetchData();
    }, [url]);

    return { data, loading, error };
};
```

**Utilisation :**
```typescript
const UserList = () => {
    const { data: users, loading, error } = useApi<User[]>('https://jsonplaceholder.typicode.com/users');

    if (loading) return <div>Chargement...</div>;
    if (error) return <div>Erreur : {error}</div>;

    return (
        <ul>
            {users?.map(user => (
                <li key={user.id}>{user.name}</li>
            ))}
        </ul>
    );
};
```



## Bonnes pratiques

### 1. Convention de nommage
- Toujours commencer par `use`
- Nom descriptif : `useCounter`, `useAuth`, `useLocalStorage`

### 2. Retour de valeurs
```typescript
// ✅ Objet pour plusieurs valeurs liées
return { user, login, logout, loading };

// ✅ Tableau pour des valeurs simples
return [value, setValue] as const;

// ✅ Valeur unique si une seule donnée
return isOnline;
```

### 3. Gestion des dépendances
```typescript
// ✅ Bien gérer les dépendances useEffect
useEffect(() => {
    // logique
}, [dependency1, dependency2]);

// ✅ Cleanup si nécessaire
useEffect(() => {
    const timer = setInterval(() => {}, 1000);
    return () => clearInterval(timer);
}, []);
```

### 4. Types TypeScript
```typescript
// ✅ Typer les paramètres et le retour
export const useCounter = (initialValue: number = 0): CounterReturn => {
    // ...
    return { count, increment, decrement, reset };
};

interface CounterReturn {
    count: number;
    increment: () => void;
    decrement: () => void;
    reset: () => void;
}
```

## Avantages des hooks personnalisés

1. **Réutilisabilité** : Partager la logique entre composants
2. **Séparation des responsabilités** : Isoler la logique métier
3. **Lisibilité** : Composants plus propres et focalisés
4. **Testabilité** : Logique isolée plus facile à tester
5. **Maintenabilité** : Modifications centralisées


Les hooks personnalisés sont un outil essentiel pour créer des applications React maintenables et réutilisables. Ils permettent d'abstraire la logique complexe et de créer des composants plus simples et focalisés sur leur rôle de présentation.
