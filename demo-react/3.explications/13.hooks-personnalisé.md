# Hooks personnalisés

### Qu'est-ce qu'un hook personnalisé ?
- Un hook personnalisé est une fonction JavaScript dont le nom commence par "use" et qui peut appeler d'autres hooks React. Ils permettent de réutiliser de la logique d'état et des effets dans plusieurs composants, favorisant ainsi l'évolution et la maintenabilité du code.

### Regles pour créer un hook personnalisé
1. Le nom du hook doit commencer par "use" (par exemple, `useFetch`, `useForm`).
2. Un hook personnalisé peut utiliser d'autres hooks React (comme `useState`, `useEffect`, etc.) à l'intérieur de sa définition.
3. Les hooks personnalisés doivent être appelés au niveau supérieur d'un composant fonctionnel ou d'un autre hook personnalisé, et ne doivent pas être appelés à l'intérieur de boucles, de conditions ou de fonctions imbriquées.

### Exemple de hook personnalisé : useFetch
Voici un exemple simple de hook personnalisé `useFetch` qui effectue une requête HTTP et gère l'état de chargement et les erreurs :

```jsx
import { useState, useEffect } from 'react';

const useFetch = (url) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch(url);
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const result = await response.json();
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    fetchData();
  }, [url]);

  return { data, loading, error };
};

export default useFetch;
```

### Utilisation du hook personnalisé useFetch
Voici comment utiliser le hook personnalisé `useFetch` dans un composant React :
```jsx
import React from 'react';
import useFetch from './useFetch';
const FetchComponent = () => {
  const { data, loading, error } = useFetch('https://api.example.com/data');

  if (loading) {
    return <div>Loading...</div>;
  }

  if (error) {
    return <div>Error: {error.message}</div>;
  }

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};
export default FetchComponent;
```
