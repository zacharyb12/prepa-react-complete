#  Maintenant que nous avons vu une bonne partie des concepts de base de React, il est temps d'aborder la structure d'une application React.

### Dossiers et fichiers principaux
- On retrouve tout ce qui touche à l'affichage dans les dossiers `components` et `pages`.
- Le dossier `services` contient généralement les fonctions qui font des appels API.
- Le dossier `hooks` est destiné aux hooks personnalisés que l'on crée pour réutiliser de la logique.
- Le dossier `utils` peut contenir des fonctions utilitaires réutilisables dans toute l'application.

### Exemple de structure de projet
```my-react-app/
├── public/
├── src/
│   ├── components/
│   ├── pages/
│   ├── services/
│   ├── hooks/
│   └── utils/
├── App.js
├── index.js
└── package.json
```
### Structure d'un appel API
Lorsqu'on effectue des appels API dans une application React, il est recommandé de structurer le code de manière à séparer la logique de l'appel API de la logique de l'interface utilisateur. Voici comment on peut organiser cela :
1. **Créer un service pour l'appel API** : Dans le dossier `services`, on crée un fichier (par exemple `apiService.js`) qui contient les fonctions responsables des appels API.

```jsx
import axios from 'axios';

const API_URL = 'https://api.example.com';

export const fetchData = async (endpoint) => {
  try {
    const response = await axios.get(`${API_URL}/${endpoint}`);
    return response.data;
  } catch (error) {
    console.error('Error fetching data:', error);
    throw error;
  }
};
```
2. **Utiliser un hook personnalisé pour gérer l'état de l'appel API** : Dans le dossier `hooks`, on peut créer un hook personnalisé (par exemple `useApi.js`) qui utilise le service pour effectuer l'appel API et gérer l'état de chargement, les données et les erreurs.

```jsx
import { useState, useEffect } from 'react';
import { fetchData } from '../services/apiService';
const useApi = (endpoint) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const getData = async () => {
      try {
        const result = await fetchData(endpoint);
        setData(result);
      } catch (error) {
        setError(error);
      } finally {
        setLoading(false);
      }
    };

    getData();
  }, [endpoint]);

  return { data, loading, error };
};
export default useApi;
```
3. **Utiliser le hook dans un composant** : Enfin, dans les composants situés dans le dossier `components` ou `pages`, on peut utiliser le hook personnalisé pour afficher les données.

```jsx
import React from 'react';
import useApi from '../hooks/useApi';
const DataDisplay = () => {
  const { data, loading, error } = useApi('data-endpoint');

  if (loading) {
    return <div>Loading...</div>;
  }

  if (error) {
    return <div>Error: {error.message}</div>;
  }

  return (
    <div>
      <h1>Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};
export default DataDisplay;
```
