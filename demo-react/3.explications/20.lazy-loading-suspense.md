# Lazy Loading et Suspense

### Qu'est-ce que le Lazy Loading ?
Le lazy loading permet de charger des composants uniquement quand ils sont nécessaires, ce qui améliore les performances initiales de l'application.

### Qu'est-ce que Suspense ?
Suspense permet d'afficher un état de chargement pendant qu'un composant est en cours de chargement (lazy loading, appels API, etc.).

---

## React.lazy()

### Chargement de composants à la demande

```tsx
import { lazy, Suspense } from 'react';

// ✅ Import normal - chargé immédiatement
import Header from './components/Header';

// ✅ Import lazy - chargé quand nécessaire
const Dashboard = lazy(() => import('./pages/Dashboard'));
const Profile = lazy(() => import('./pages/Profile'));
const Settings = lazy(() => import('./pages/Settings'));

function App() {
  return (
    <div>
      <Header />
      
      <Suspense fallback={<div>Chargement de la page...</div>}>
        <Routes>
          <Route path="/dashboard" element={<Dashboard />} />
          <Route path="/profile" element={<Profile />} />
          <Route path="/settings" element={<Settings />} />
        </Routes>
      </Suspense>
    </div>
  );
}
```

### Exemple avec React Router

```tsx
import { BrowserRouter as Router, Routes, Route } from 'react-router-dom';
import { lazy, Suspense } from 'react';

// Pages lazy-loaded
const HomePage = lazy(() => import('./pages/HomePage'));
const ProductsPage = lazy(() => import('./pages/ProductsPage'));
const ProductDetailPage = lazy(() => import('./pages/ProductDetailPage'));
const CartPage = lazy(() => import('./pages/CartPage'));
const CheckoutPage = lazy(() => import('./pages/CheckoutPage'));

// Composant de chargement
function PageLoader() {
  return (
    <div className="page-loader">
      <div className="spinner"></div>
      <p>Chargement...</p>
    </div>
  );
}

function App() {
  return (
    <Router>
      <div className="app">
        <nav>
          <Link to="/">Accueil</Link>
          <Link to="/products">Produits</Link>
          <Link to="/cart">Panier</Link>
        </nav>

        <main>
          <Suspense fallback={<PageLoader />}>
            <Routes>
              <Route path="/" element={<HomePage />} />
              <Route path="/products" element={<ProductsPage />} />
              <Route path="/products/:id" element={<ProductDetailPage />} />
              <Route path="/cart" element={<CartPage />} />
              <Route path="/checkout" element={<CheckoutPage />} />
            </Routes>
          </Suspense>
        </main>
      </div>
    </Router>
  );
}
```

## Suspense avancé

### Fallback personnalisés par section

```tsx
function App() {
  return (
    <div>
      <Header />
      
      {/* Suspense pour la navigation principale */}
      <Suspense fallback={<NavigationSkeleton />}>
        <MainNavigation />
      </Suspense>

      {/* Suspense pour le contenu principal */}
      <Suspense fallback={<ContentSkeleton />}>
        <MainContent />
      </Suspense>

      {/* Suspense pour la sidebar */}
      <Suspense fallback={<SidebarSkeleton />}>
        <Sidebar />
      </Suspense>
    </div>
  );
}

// Composants skeleton pour un meilleur UX
function ContentSkeleton() {
  return (
    <div className="content-skeleton">
      <div className="skeleton-title"></div>
      <div className="skeleton-paragraph"></div>
      <div className="skeleton-paragraph"></div>
    </div>
  );
}

function NavigationSkeleton() {
  return (
    <nav className="nav-skeleton">
      {[...Array(5)].map((_, i) => (
        <div key={i} className="skeleton-nav-item"></div>
      ))}
    </nav>
  );
}
```

### Gestion d'erreurs avec ErrorBoundary

```tsx
import { ErrorBoundary } from 'react-error-boundary';

function ErrorFallback({ error, resetErrorBoundary }: {
  error: Error;
  resetErrorBoundary: () => void;
}) {
  return (
    <div role="alert" className="error-fallback">
      <h2>Oops! Quelque chose s'est mal passé</h2>
      <p>{error.message}</p>
      <button onClick={resetErrorBoundary}>Réessayer</button>
    </div>
  );
}

function App() {
  return (
    <ErrorBoundary FallbackComponent={ErrorFallback}>
      <Suspense fallback={<PageLoader />}>
        <Router>
          <Routes>
            <Route path="/" element={<HomePage />} />
            <Route path="/products" element={<ProductsPage />} />
          </Routes>
        </Router>
      </Suspense>
    </ErrorBoundary>
  );
}
```

## Lazy loading conditionnel

### Charger des composants selon des conditions

```tsx
function AdminPanel() {
  const { user } = useAuth();
  const [showAdvanced, setShowAdvanced] = useState(false);

  // Charger le composant avancé seulement si nécessaire
  const AdvancedSettings = lazy(() => import('./AdvancedSettings'));
  const UserManagement = lazy(() => import('./UserManagement'));

  if (!user?.isAdmin) {
    return <div>Accès refusé</div>;
  }

  return (
    <div>
      <h1>Panel Admin</h1>
      
      <button onClick={() => setShowAdvanced(!showAdvanced)}>
        {showAdvanced ? 'Masquer' : 'Afficher'} les paramètres avancés
      </button>

      {showAdvanced && (
        <Suspense fallback={<div>Chargement des paramètres avancés...</div>}>
          <AdvancedSettings />
        </Suspense>
      )}

      <Suspense fallback={<div>Chargement de la gestion utilisateurs...</div>}>
        <UserManagement />
      </Suspense>
    </div>
  );
}
```

### Lazy loading basé sur l'interaction

```tsx
function ProductCard({ product }: { product: Product }) {
  const [showDetails, setShowDetails] = useState(false);

  // Charger le composant de détails seulement quand demandé
  const ProductDetails = lazy(() => import('./ProductDetails'));

  return (
    <div className="product-card">
      <h3>{product.name}</h3>
      <p>{product.price}€</p>
      
      <button onClick={() => setShowDetails(!showDetails)}>
        {showDetails ? 'Masquer' : 'Voir'} les détails
      </button>

      {showDetails && (
        <Suspense fallback={<div>Chargement des détails...</div>}>
          <ProductDetails product={product} />
        </Suspense>
      )}
    </div>
  );
}
```

## Code Splitting par routes

### Organisation des chunks

```tsx
// utils/lazyImport.ts
export function lazyImport<T extends Record<string, any>>(
  factory: () => Promise<T>,
  name: keyof T
) {
  return lazy(() =>
    factory().then((module) => ({
      default: module[name] as React.ComponentType<any>,
    }))
  );
}

// Utilisation
const HomePage = lazyImport(() => import('./pages/HomePage'), 'HomePage');
const ProductsPage = lazyImport(() => import('./pages/ProductsPage'), 'ProductsPage');
```

### Préchargement intelligent

```tsx
// Précharger les routes probables
function HomePage() {
  useEffect(() => {
    // Précharger la page produits après 2 secondes
    const timer = setTimeout(() => {
      import('./pages/ProductsPage');
    }, 2000);

    return () => clearTimeout(timer);
  }, []);

  // Précharger au hover
  const handleProductsHover = () => {
    import('./pages/ProductsPage');
  };

  return (
    <div>
      <h1>Accueil</h1>
      <Link 
        to="/products" 
        onMouseEnter={handleProductsHover}
      >
        Voir les produits
      </Link>
    </div>
  );
}
```

```tsx
function App() {

```

### Hook personnalisé avec Suspense

```tsx
// Hook qui utilise le pattern Suspense
function useSuspenseData<T>(key: string, fetcher: () => Promise<T>): T {
  const [data, setData] = useState<T | null>(null);
  const [promise, setPromise] = useState<Promise<T> | null>(null);

  if (data === null && promise === null) {
    const newPromise = fetcher().then((result) => {
      setData(result);
      return result;
    });
    setPromise(newPromise);
    throw newPromise; // Suspense catchera cette promesse
  }

  if (data === null && promise) {
    throw promise; // Toujours en cours de chargement
  }

  return data as T;
}

// Utilisation
function ProductList() {
  const products = useSuspenseData('products', () => 
    fetch('/api/products').then(res => res.json())
  );

  return (
    <div>
      {products.map(product => (
        <ProductCard key={product.id} product={product} />
      ))}
    </div>
  );
}
```

## Optimisations avancées

### Grouper les imports

```tsx
// ❌ Chaque composant crée un chunk séparé
const Component1 = lazy(() => import('./Component1'));
const Component2 = lazy(() => import('./Component2'));
const Component3 = lazy(() => import('./Component3'));

// ✅ Grouper les composants liés
const { Component1, Component2, Component3 } = lazy(() => 
  Promise.all([
    import('./Component1'),
    import('./Component2'),
    import('./Component3'),
  ]).then(([mod1, mod2, mod3]) => ({
    default: {
      Component1: mod1.default,
      Component2: mod2.default,
      Component3: mod3.default,
    }
  }))
);
```

### Retry pattern pour les échecs de chargement

```tsx
function RetryableComponent({ children, fallback }: {
  children: React.ReactNode;
  fallback: React.ComponentType<{ retry: () => void }>;
}) {
  const [retryKey, setRetryKey] = useState(0);

  const retry = useCallback(() => {
    setRetryKey(prev => prev + 1);
  }, []);

  return (
    <ErrorBoundary
      key={retryKey}
      fallbackRender={({ error, resetErrorBoundary }) => (
        <fallback retry={resetErrorBoundary} />
      )}
    >
      <Suspense fallback={<div>Chargement...</div>}>
        {children}
      </Suspense>
    </ErrorBoundary>
  );
}

// Utilisation
function App() {
  return (
    <RetryableComponent 
      fallback={({ retry }) => (
        <div>
          <p>Erreur de chargement</p>
          <button onClick={retry}>Réessayer</button>
        </div>
      )}
    >
      <LazyComponent />
    </RetryableComponent>
  );
}
```

## Bonnes pratiques

### ✅ Quand utiliser le lazy loading

1. **Routes/Pages** - Toujours une bonne idée
2. **Composants lourds** - Modals, éditeurs, graphiques
3. **Fonctionnalités conditionnelles** - Admin panels, outils avancés
4. **Composants peu utilisés** - Pages d'erreur, aide

### ✅ Conseils d'optimisation

1. **Précharger intelligemment**
```tsx
// Au hover ou après l'interaction utilisateur
const handleHover = () => import('./HeavyComponent');
```

2. **Utiliser des skeletons**
```tsx
// Meilleur UX qu'un simple "Chargement..."
<Suspense fallback={<ProductListSkeleton />}>
  <ProductList />
</Suspense>
```

3. **Grouper les imports liés**
```tsx
// Composants utilisés ensemble
const AdminComponents = lazy(() => import('./admin'));
```

### ❌ Erreurs à éviter

1. **Lazy loading de tout** - Composants critiques doivent être chargés immédiatement
2. **Fallbacks inadaptés** - Skeleton > spinner > texte simple
3. **Oublier la gestion d'erreurs** - Toujours wraper avec ErrorBoundary
4. **Suspense trop granulaire** - Éviter un Suspense par petit composant
