# Ajax : fetch et axios

L'Ajax (Asynchronous JavaScript and XML) est une technique qui permet de charger des données en arrière-plan sans recharger la page entière. En React, deux des méthodes les plus courantes pour effectuer des requêtes Ajax sont `fetch` et `axios`.

## Utilisation de fetch
`fetch` est une API native de JavaScript qui permet de faire des requêtes HTTP. Voici un exemple simple d'utilisation de `fetch` dans un composant React :

```jsx
import React, { useEffect, useState } from 'react';

const FetchExample = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    fetch('https://api.example.com/data')
      .then((response) => response.json())
      .then((data) => setData(data))
      .catch((error) => console.error('Error fetching data:', error));
  }, []);

  if (!data) {
    return <div>Loading...</div>;
  }

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default FetchExample;
```

## Utilisation d'axios
`axios` est une bibliothèque tierce qui facilite les requêtes HTTP. Elle offre une syntaxe plus simple et des fonctionnalités supplémentaires par rapport à `fetch`. Voici un exemple d'utilisation d'`axios` dans un composant React :

```jsx
import React, { useEffect, useState } from 'react';
import axios from 'axios';
const AxiosExample = () => {
  const [data, setData] = useState(null);

  useEffect(() => {
    axios.get('https://api.example.com/data')
      .then((response) => setData(response.data))
      .catch((error) => console.error('Error fetching data:', error));
  }, []);

  if (!data) {
    return <div>Loading...</div>;
  }

  return (
    <div>
      <h1>Fetched Data</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default AxiosExample;
```

## Conclusion
Les deux méthodes, `fetch` et `axios`, sont efficaces pour effectuer des requêtes Ajax
en React. Le choix entre les deux dépend souvent des préférences personnelles et des besoins spécifiques du projet. `fetch` est intégré à JavaScript et ne nécessite pas d'installation supplémentaire, tandis qu'`axios` offre une syntaxe plus conviviale et des fonctionnalités avancées comme l'annulation des requêtes et la gestion automatique des JSON.
