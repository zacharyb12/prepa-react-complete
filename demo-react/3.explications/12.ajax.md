# Ajax et structure des projets React

### Introduction

- Dans les applications React, il est courant de devoir récupérer des données depuis une API externe. Pour cela, nous utilisons souvent des requêtes AJAX. Cependant, il est important de structurer correctement notre projet pour maintenir un code propre et organisé.

- Pour gérer les requêtes AJAX, il existe plusieurs bibliothèques populaires comme Axios ou Fetch API. Dans cet exemple, nous allons utiliser Axios pour effectuer des requêtes HTTP.

- Il suffit de fournir l'adresse de l'API et de traiter la réponse.

### Exemple d'appel API

#### Fetch
- Avec Fetch, il est nécessaire de parser la réponse en JSON avant de pouvoir utiliser les données.
```javascript
fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error('Error fetching data:', error);
    });
```

#### Axios
- Il n'est pas nécessaire de parser la réponse avec Axios, car les données sont déjà parsées automatiquement.
```javascript
import axios from 'axios';

axios.get('https://api.example.com/data')
    .then(response => {
        console.log(response.data);
    })
    .catch(error => {
        console.error('Error fetching data:', error);
    });
```

### Structuration du projet

- Pour une meilleure organisation, il est recommandé de créer un dossier `api` dans le répertoire `src` de votre projet React. Ce dossier contiendra tous les fichiers liés aux appels API.

- Par exemple, vous pouvez créer un fichier `apiService.js` dans le dossier `api` pour gérer les appels à une API spécifique.

```javascript
import axios from 'axios';

const API_URL = 'https://api.example.com';

export const fetchData = async () => {
    try {
        const response = await axios.get(`${API_URL}/data`);
        return response.data;
    } catch (error) {
        console.error('Error fetching data:', error);
        throw error;
    }
};
```

### Exemple concret : Système d'authentification

#### Structure des fichiers

```
src/
├── api/
│   └── demoAuthApi.ts          # Appels API d'authentification
├── contexts/
│   ├── demoAuthContext.tsx     # Provider d'authentification
│   └── useAuth.tsx             # Hook personnalisé
└── components/
    └── LoginForm.tsx           # Composant de connexion
```

#### 1. API d'authentification (`api/demoAuthApi.ts`)

```typescript
import axios from 'axios';

interface User {
    id: number;
    name: string;
    email: string;
}

interface LoginForm {
    email: string;
    password: string;
}

export const AuthApi = {
    // Connexion utilisateur
    login: async (loginForm: LoginForm) => {
        const response = await axios.post('https://jsonplaceholder.typicode.com/posts', loginForm);
        
        if (loginForm.email && loginForm.password) {
            const userData = { id: 1, name: "John Doe", email: "demo@test.com" };
            const token = "demo-token-123";
            
            // Sauvegarde dans localStorage
            localStorage.setItem('authToken', token);
            localStorage.setItem('user', JSON.stringify(userData));
            
            return { user: userData, token };
        }
        
        throw new Error("Email et mot de passe requis");
    },

    // Vérification du token
    verifyToken: async (token: string) => {
        await axios.get('https://jsonplaceholder.typicode.com/posts/1');
        
        if (token === "demo-token-123") {
            return { id: 1, name: "John Doe", email: "demo@test.com" };
        }
        
        throw new Error("Token invalide");
    },

    // Déconnexion
    logout: async () => {
        await axios.delete('https://jsonplaceholder.typicode.com/posts/1');
        localStorage.removeItem('authToken');
        localStorage.removeItem('user');
        return { success: true };
    },

    // Utilitaires localStorage
    getStoredToken: () => localStorage.getItem('authToken'),
    getStoredUser: () => {
        const userStr = localStorage.getItem('user');
        return userStr ? JSON.parse(userStr) : null;
    },
    clearStorage: () => {
        localStorage.removeItem('authToken');
        localStorage.removeItem('user');
    }
};
```

#### 2. Context d'authentification (`contexts/demoAuthContext.tsx`)

```typescript
import { createContext, useEffect, useState, type ReactNode } from "react";
import { AuthApi } from "../api/demoAuthApi";

interface User {
    id: number;
    name: string;
    email: string;
}

interface AuthContextType {
    user: User | null;
    isAuthenticated: boolean;
    login: (email: string, password: string) => Promise<void>;
    logout: () => void;
    loading: boolean;
}

const AuthContext = createContext<AuthContextType | null>(null);

export { AuthContext };

export const AuthProvider = ({ children }: { children: ReactNode }) => {
    const [user, setUser] = useState<User | null>(null);
    const [loading, setLoading] = useState(true);

    // Vérifier l'authentification au chargement
    useEffect(() => {
        const checkAuth = async () => {
            const token = AuthApi.getStoredToken();
            if (token) {
                try {
                    const userData = await AuthApi.verifyToken(token);
                    setUser(userData);
                } catch {
                    AuthApi.clearStorage();
                }
            }
            setLoading(false);
        };
        checkAuth();
    }, []);

    // Fonction de connexion
    const login = async (email: string, password: string) => {
        const response = await AuthApi.login({ email, password });
        setUser(response.user);
    };

    // Fonction de déconnexion
    const logout = () => {
        AuthApi.logout();
        setUser(null);
    };

    return (
        <AuthContext.Provider value={{
            user,
            isAuthenticated: !!user,
            login,
            logout,
            loading
        }}>
            {children}
        </AuthContext.Provider>
    );
};
```

#### 3. Hook personnalisé (`contexts/useAuth.tsx`)

```typescript
import { useContext } from "react";
import { AuthContext } from "./demoAuthContext";

export const useAuth = () => {
    const context = useContext(AuthContext);
    if (!context) {
        throw new Error('useAuth must be used within AuthProvider');
    }
    return context;
};
```

#### 4. Utilisation dans un composant

```typescript
import { useAuth } from '../contexts/useAuth';

const LoginForm = () => {
    const { login, user, isAuthenticated, loading } = useAuth();
    
    const handleLogin = async () => {
        try {
            await login('demo@test.com', 'password');
            console.log('Connexion réussie !');
        } catch (error) {
            console.error('Erreur de connexion:', error);
        }
    };
    
    if (loading) return <div>Chargement...</div>;
    if (isAuthenticated) return <div>Connecté : {user?.name}</div>;
    
    return <button onClick={handleLogin}>Se connecter</button>;
};
```

### Étapes de mise en place

1. **Installer Axios** : `npm install axios`
2. **Créer l'API** : Définir les appels HTTP dans le dossier `api/`
3. **Créer le Context** : Gérer l'état global dans `contexts/`
4. **Créer le Hook** : Simplifier l'utilisation avec `useAuth()`
5. **Wrapper l'App** : Entourer l'application avec `<AuthProvider>`
6. **Utiliser dans les composants** : Importer `useAuth()` où nécessaire

### Avantages de cette structure

- **Séparation des responsabilités** : API, état, et interface séparés
- **Réutilisabilité** : Le hook peut être utilisé dans tous les composants
- **Persistence** : Gestion automatique du localStorage
- **Type Safety** : Types TypeScript pour éviter les erreurs
- **Maintenance** : Code organisé et facile à maintenir

En suivant cette structure, vous facilitez la maintenance et l'évolution de votre code, tout en gardant une séparation claire entre la logique de récupération des données et la présentation dans vos composants React.
