# Optimisation avec memo, useCallback et useMemo

### Pourquoi optimiser ?
React re-rend un composant quand :
- Son état change
- Ses props changent  
- Son composant parent re-rend

Ces optimisations permettent d'éviter des re-renders inutiles et des calculs coûteux.

---

## React.memo

### Qu'est-ce que React.memo ?
`React.memo` est un HOC (Higher-Order Component) qui mémorise un composant et ne le re-rend que si ses props changent.

### Exemple de base

```tsx
// Composant qui se re-rend à chaque fois
function ExpensiveComponent({ name, count }: { name: string; count: number }) {
  console.log('ExpensiveComponent rendu'); // Se déclenche à chaque parent re-render
  
  return (
    <div>
      <h3>{name}</h3>
      <p>Count: {count}</p>
    </div>
  );
}

// Composant optimisé avec memo
const OptimizedComponent = React.memo(function OptimizedComponent({ 
  name, 
  count 
}: { 
  name: string; 
  count: number 
}) {
  console.log('OptimizedComponent rendu'); // Ne se déclenche que si name ou count change
  
  return (
    <div>
      <h3>{name}</h3>
      <p>Count: {count}</p>
    </div>
  );
});
```

### Exemple avec comparaison personnalisée

```tsx
interface User {
  id: number;
  name: string;
  email: string;
  lastLogin: Date;
}

const UserCard = React.memo(function UserCard({ user }: { user: User }) {
  return (
    <div>
      <h3>{user.name}</h3>
      <p>{user.email}</p>
    </div>
  );
}, (prevProps, nextProps) => {
  // Ne re-rendre que si name ou email change (ignorer lastLogin)
  return prevProps.user.name === nextProps.user.name &&
         prevProps.user.email === nextProps.user.email;
});
```

## useCallback

### Qu'est-ce que useCallback ?
`useCallback` mémorise une fonction et ne la recrée que si ses dépendances changent.

### Problème sans useCallback

```tsx
function ParentComponent() {
  const [count, setCount] = useState(0);
  const [name, setName] = useState('');

  // ❌ Nouvelle fonction créée à chaque render
  const handleClick = () => {
    console.log('Button clicked');
  };

  return (
    <div>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      
      {/* Ce composant se re-rend même quand seul 'name' change */}
      <ExpensiveChildComponent onClick={handleClick} />
    </div>
  );
}

const ExpensiveChildComponent = React.memo(function ExpensiveChildComponent({ 
  onClick 
}: { 
  onClick: () => void 
}) {
  console.log('ExpensiveChildComponent rendu');
  return <button onClick={onClick}>Click me</button>;
});
```

### Solution avec useCallback

```tsx
function ParentComponent() {
  const [count, setCount] = useState(0);
  const [name, setName] = useState('');

  // ✅ Fonction mémorisée
  const handleClick = useCallback(() => {
    console.log('Button clicked');
  }, []); // Pas de dépendances = fonction stable

  const handleIncrement = useCallback(() => {
    setCount(prev => prev + 1); // Utiliser la fonction de mise à jour
  }, []); // Pas besoin de 'count' dans les dépendances

  return (
    <div>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <p>Count: {count}</p>
      <button onClick={handleIncrement}>Increment</button>
      
      {/* Ce composant ne se re-rend plus quand 'name' change */}
      <ExpensiveChildComponent onClick={handleClick} />
    </div>
  );
}
```

### Exemple avec dépendances

```tsx
function ProductList({ products }: { products: Product[] }) {
  const [filter, setFilter] = useState('');
  const [sortBy, setSortBy] = useState<'name' | 'price'>('name');

  // ✅ Fonction qui dépend de 'sortBy'
  const handleSort = useCallback((newSortBy: 'name' | 'price') => {
    setSortBy(newSortBy);
    console.log(`Sorting by ${newSortBy}`);
  }, [sortBy]); // Se recrée quand sortBy change

  // ✅ Fonction qui dépend de 'filter'
  const handleSearch = useCallback((searchTerm: string) => {
    setFilter(searchTerm);
    // Logique de recherche...
  }, [filter]);

  return (
    <div>
      <SearchInput onSearch={handleSearch} />
      <SortButtons onSort={handleSort} currentSort={sortBy} />
      <ProductGrid products={products} />
    </div>
  );
}
```

## useMemo

### Qu'est-ce que useMemo ?
`useMemo` mémorise le résultat d'un calcul coûteux et ne le recalcule que si ses dépendances changent.

### Exemple de calcul coûteux

```tsx
function ProductList({ products }: { products: Product[] }) {
  const [filter, setFilter] = useState('');
  const [sortBy, setSortBy] = useState<'name' | 'price'>('name');

  // ❌ Calcul refait à chaque render
  const filteredAndSortedProducts = products
    .filter(product => product.name.toLowerCase().includes(filter.toLowerCase()))
    .sort((a, b) => {
      if (sortBy === 'name') {
        return a.name.localeCompare(b.name);
      }
      return a.price - b.price;
    });

  return (
    <div>
      <input 
        value={filter} 
        onChange={(e) => setFilter(e.target.value)}
        placeholder="Filtrer les produits..." 
      />
      <select value={sortBy} onChange={(e) => setSortBy(e.target.value as 'name' | 'price')}>
        <option value="name">Trier par nom</option>
        <option value="price">Trier par prix</option>
      </select>
      
      {filteredAndSortedProducts.map(product => (
        <ProductCard key={product.id} product={product} />
      ))}
    </div>
  );
}
```

### Solution avec useMemo

```tsx
function ProductList({ products }: { products: Product[] }) {
  const [filter, setFilter] = useState('');
  const [sortBy, setSortBy] = useState<'name' | 'price'>('name');

  // ✅ Calcul mémorisé
  const filteredAndSortedProducts = useMemo(() => {
    console.log('Recalcul des produits'); // Ne s'affiche que quand nécessaire
    
    return products
      .filter(product => 
        product.name.toLowerCase().includes(filter.toLowerCase())
      )
      .sort((a, b) => {
        if (sortBy === 'name') {
          return a.name.localeCompare(b.name);
        }
        return a.price - b.price;
      });
  }, [products, filter, sortBy]); // Recalcule si ces valeurs changent

  // ✅ Mémoriser des calculs simples aussi
  const productCount = useMemo(() => filteredAndSortedProducts.length, [filteredAndSortedProducts]);
  
  const averagePrice = useMemo(() => {
    if (filteredAndSortedProducts.length === 0) return 0;
    const total = filteredAndSortedProducts.reduce((sum, product) => sum + product.price, 0);
    return total / filteredAndSortedProducts.length;
  }, [filteredAndSortedProducts]);

  return (
    <div>
      <div>
        <p>{productCount} produits trouvés</p>
        <p>Prix moyen: {averagePrice.toFixed(2)}€</p>
      </div>
      
      <input 
        value={filter} 
        onChange={(e) => setFilter(e.target.value)}
        placeholder="Filtrer les produits..." 
      />
      
      <select value={sortBy} onChange={(e) => setSortBy(e.target.value as 'name' | 'price')}>
        <option value="name">Trier par nom</option>
        <option value="price">Trier par prix</option>
      </select>
      
      {filteredAndSortedProducts.map(product => (
        <ProductCard key={product.id} product={product} />
      ))}
    </div>
  );
}
```

## Exemple complet : TodoList optimisée

```tsx
interface Todo {
  id: number;
  text: string;
  completed: boolean;
  createdAt: Date;
}

// Composant Todo optimisé
const TodoItem = React.memo(function TodoItem({ 
  todo, 
  onToggle, 
  onDelete 
}: {
  todo: Todo;
  onToggle: (id: number) => void;
  onDelete: (id: number) => void;
}) {
  console.log(`TodoItem ${todo.id} rendu`);

  // ✅ Éviter de créer de nouvelles fonctions à chaque render
  const handleToggle = useCallback(() => {
    onToggle(todo.id);
  }, [todo.id, onToggle]);

  const handleDelete = useCallback(() => {
    onDelete(todo.id);
  }, [todo.id, onDelete]);

  return (
    <div className={`todo-item ${todo.completed ? 'completed' : ''}`}>
      <input 
        type="checkbox" 
        checked={todo.completed} 
        onChange={handleToggle}
      />
      <span>{todo.text}</span>
      <button onClick={handleDelete}>Supprimer</button>
    </div>
  );
});

function TodoList() {
  const [todos, setTodos] = useState<Todo[]>([]);
  const [filter, setFilter] = useState<'all' | 'active' | 'completed'>('all');
  const [newTodoText, setNewTodoText] = useState('');

  // ✅ Fonctions stables avec useCallback
  const addTodo = useCallback((text: string) => {
    const newTodo: Todo = {
      id: Date.now(),
      text,
      completed: false,
      createdAt: new Date()
    };
    setTodos(prev => [...prev, newTodo]);
  }, []);

  const toggleTodo = useCallback((id: number) => {
    setTodos(prev => prev.map(todo =>
      todo.id === id ? { ...todo, completed: !todo.completed } : todo
    ));
  }, []);

  const deleteTodo = useCallback((id: number) => {
    setTodos(prev => prev.filter(todo => todo.id !== id));
  }, []);

  const handleSubmit = useCallback((e: React.FormEvent) => {
    e.preventDefault();
    if (newTodoText.trim()) {
      addTodo(newTodoText.trim());
      setNewTodoText('');
    }
  }, [newTodoText, addTodo]);

  // ✅ Calculs mémorisés
  const filteredTodos = useMemo(() => {
    switch (filter) {
      case 'active':
        return todos.filter(todo => !todo.completed);
      case 'completed':
        return todos.filter(todo => todo.completed);
      default:
        return todos;
    }
  }, [todos, filter]);

  const stats = useMemo(() => ({
    total: todos.length,
    completed: todos.filter(todo => todo.completed).length,
    active: todos.filter(todo => !todo.completed).length
  }), [todos]);

  return (
    <div>
      <h1>Todo List</h1>
      
      {/* Statistiques */}
      <div>
        <p>Total: {stats.total} | Actives: {stats.active} | Terminées: {stats.completed}</p>
      </div>

      {/* Formulaire d'ajout */}
      <form onSubmit={handleSubmit}>
        <input
          value={newTodoText}
          onChange={(e) => setNewTodoText(e.target.value)}
          placeholder="Nouvelle tâche..."
        />
        <button type="submit">Ajouter</button>
      </form>

      {/* Filtres */}
      <div>
        <button 
          onClick={() => setFilter('all')}
          className={filter === 'all' ? 'active' : ''}
        >
          Toutes
        </button>
        <button 
          onClick={() => setFilter('active')}
          className={filter === 'active' ? 'active' : ''}
        >
          Actives
        </button>
        <button 
          onClick={() => setFilter('completed')}
          className={filter === 'completed' ? 'active' : ''}
        >
          Terminées
        </button>
      </div>

      {/* Liste des todos */}
      <div>
        {filteredTodos.map(todo => (
          <TodoItem
            key={todo.id}
            todo={todo}
            onToggle={toggleTodo}
            onDelete={deleteTodo}
          />
        ))}
      </div>
    </div>
  );
}
```

## Bonnes pratiques et pièges

### ✅ Bonnes pratiques

1. **Mesurer avant d'optimiser**
```tsx
// Utiliser React DevTools Profiler pour identifier les vrais problèmes
```

2. **Optimiser les props objets**
```tsx
// ❌ Objet recréé à chaque render
<Component config={{ theme: 'dark', size: 'large' }} />

// ✅ Objet mémorisé
const config = useMemo(() => ({ theme: 'dark', size: 'large' }), []);
<Component config={config} />
```

3. **Utiliser les fonctions de mise à jour**
```tsx
// ✅ Pas besoin de count dans les dépendances
const increment = useCallback(() => {
  setCount(prev => prev + 1);
}, []);
```

### ❌ Pièges à éviter

1. **Sur-optimisation**
```tsx
// ❌ Inutile pour des calculs simples
const doubled = useMemo(() => count * 2, [count]);

// ✅ Calcul direct plus efficace
const doubled = count * 2;
```

2. **Dépendances manquantes**
```tsx
// ❌ 'name' manque dans les dépendances
const greeting = useCallback(() => {
  console.log(`Hello ${name}`);
}, []); // Bug potentiel !

// ✅ Toutes les dépendances présentes
const greeting = useCallback(() => {
  console.log(`Hello ${name}`);
}, [name]);
```

3. **Référence instable dans les dépendances**
```tsx
// ❌ 'user' est un objet qui change de référence
const userName = useMemo(() => user.name, [user]);

// ✅ Utiliser une propriété primitive
const userName = useMemo(() => user.name, [user.name]);
```

## Quand optimiser ?

### ✅ Optimiser quand :
- Profiling montre des problèmes de performance
- Composants avec beaucoup d'enfants
- Calculs réellement coûteux
- Listes longues

### ❌ Ne pas optimiser quand :
- Pas de problème de performance mesuré
- Composants simples
- Calculs triviaux
- Premature optimization

### 🔧 Outils de mesure :
- React DevTools Profiler
- Browser DevTools Performance tab
- console.time() pour mesurer des calculs
