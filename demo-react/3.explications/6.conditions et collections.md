# Conditionnel & Collections

Le rendu conditionnel en React permet d'afficher ou de masquer des éléments de l'interface utilisateur en fonction de certaines conditions. Cela est souvent utilisé pour afficher différents contenus selon l'état de l'application ou les interactions de l'utilisateur.

## Rendu conditionnel

```tsx
function App() {
  const isLoggedIn = true;

      if (isLoggedIn) {

        return (
          <div>
            <h1>Bienvenue, utilisateur !</h1>
          </div>
        );

      } else {

        return (
          <div>
            <h1>Veuillez vous connecter.</h1>
          </div>
        );

      }
}

```

```tsx
function App() {
  const isLoggedIn = true;

  return (
    <div>
      {isLoggedIn ? ( <h1>Bienvenue, utilisateur !</h1> ) : ( <h1>Veuillez vous connecter.</h1> )}
    </div>
  );
}
```
- Dans cet exemple, si `isLoggedIn` est vrai, le message de bienvenue sera affiché. Sinon, un message invitant l'utilisateur à se connecter sera montré.

### Rendu de collections

- En React, on peut rendre des listes d'éléments en utilisant la méthode `map()` pour itérer sur un tableau de données et retourner un composant pour chaque élément.

```tsx
function App() {
  const items = ['Item 1', 'Item 2', 'Item 3'];

  return (
    <div>

      <ul>
      {items.map((data) => (
          
          <li>{data}</li>
        
      ))}
        </ul>

    </div>
  );
}
```
- Dans cet exemple, chaque élément du tableau `items` est rendu comme un élément de liste `<li>` à l'intérieur d'une liste non ordonnée `<ul>`.

- une erreur est visible dans la console du navigateur : "Each child in a list should have a unique "key" prop."

- Pour corriger cette erreur, on doit ajouter une prop `key` unique à chaque élément rendu dans la liste :

```tsx
function App() {

  const items = ['Item 1', 'Item 2', 'Item 3'];

  return (
        <ul>

      { items.map( (item) => ( <li key={item.key}>{item.value}</li> ) ) }
        
        </ul>
  );
}
```
- dans le cas ou il est impossible d'avoir une clé unique, on peut utiliser l'index de l'élément dans le tableau :

```tsx
function App() {

  const items = ['Item 1', 'Item 2', 'Item 3'];

  return (
          <ul>
              {items.map((item, index) => ( <li key={index}>{item}</li> ))}
          </ul>
        );
}
```

---

il sera possible de passer une liste en paramètre d'un composant via les props :

```tsx
function ItemList({ items }: { items: Item[] }) {
  
  return (
          <ul>
              {items.map((item) => ( <li key={item.id}>{item.name}</li> ) )}
          </ul>
        );
}
