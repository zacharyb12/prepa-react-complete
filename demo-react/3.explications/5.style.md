# Le style dans React

- Le style dans une application React peut être géré de plusieurs façons, notamment via des feuilles de style CSS, des bibliothèques de styles en ligne, ou des frameworks CSS.


## Portée des styles

- Le style que l'on applique dans un composant React peut être global (affectant toute l'application) ou local (affectant uniquement le composant).

- Il sera utile de définir si le style sera réutilisable ou spécifique à un composant.

- Si on prévoit un style de base qui va s'appliquer à plusieurs composants, il est préférable de le définir dans un fichier CSS global.

- Cela n'empêche pas d'avoir des styles spécifiques dans chaque composant.

## Exemple d'utilisation d'un fichier CSS dans un composant React

```css
/* MonComposant.css */
.mon-composant {
  border: 1px solid #ccc;
  padding: 16px;
  border-radius: 8px;
}

.titre {
  color: #333;
  font-size: 24px;
}

.description {
  color: #666;
  font-size: 16px;
}
```

```tsx
// MonComposant.tsx
import './MonComposant.css';

function MonComposant() {

  return (
    <div className="mon-composant">

      <h1 className="titre">Titre de mon composant</h1>

      <p className="description">Ceci est une description de mon composant.</p>
    </div>

  );

}

export default MonComposant;
```

## Exemple d'utilisation de styles en ligne dans un composant React

- Les styles en ligne sont définis directement dans les éléments JSX en utilisant l'attribut `style`.

- Les styles en ligne sont définis sous forme d'objet JavaScript, où les propriétés CSS sont en camelCase.

- Le style en ligne fonctionne avec une syntaxe clé-valeur ( propriété: valeur ), et les valeurs doivent être des chaînes de caractères ou des nombres (pour les unités sans 'px').

```tsx
function MonComposant() {
  return (

    <div style={{ border: '1px solid #ccc', padding: '16px', borderRadius: '8px' }}>

      <h1 style={{ color: '#4539c7ff', fontSize: '24px' }}>Titre de mon composant</h1>

      <p style={{ color: 'red', fontSize: '16px', zIndex: 1 }}>Ceci est une description de mon composant.</p>

    </div>
  
  );
}

export default MonComposant;
```
--- 
### Particularités du style en React

- En React, les classes CSS sont appliquées via l'attribut `className` au lieu de `class` pour éviter les conflits avec le mot-clé JavaScript `class`.

- Il est possible d'utiliser des frameworks CSS comme Tailwind CSS ou Bootstrap pour accélérer le développement en utilisant des classes pré-définies.

- Enfin, il est important de tester les styles sur différents navigateurs et appareils pour s'assurer d'une expérience utilisateur cohérente.

---

### Bonnes pratiques

- Organiser les fichiers CSS de manière logique, par exemple en créant un dossier `styles` ou `css` dans le projet.

- Utiliser des conventions de nommage claires pour les classes CSS afin d'éviter les conflits et de faciliter la maintenance.

- Préférer les classes ou id pour éviter qu'un style d'un élément n'affecte involontairement l'application.

- Documenter les styles importants ou complexes pour faciliter la compréhension par d'autres développeurs.

---

### Installer une bibliothèque CSS ( bootstrap )

- Pour installer Bootstrap dans une application React, vous pouvez utiliser npm ou yarn.

```bash
npm install bootstrap
```

- Ensuite, vous pouvez importer le fichier CSS de Bootstrap dans votre fichier principal, généralement `index.tsx` ou `App.tsx`.

```tsx
import 'bootstrap/dist/css/bootstrap.min.css';

function App() {
  return (
    <div className="container">
      <h1 className="text-center">Bienvenue dans mon application React avec Bootstrap</h1>
      <button className="btn btn-primary">Cliquez-moi</button>
    </div>
  );
}

export default App;
```

- Maintenant, vous pouvez utiliser les classes CSS de Bootstrap dans vos composants React pour styliser vos éléments rapidement et facilement.
