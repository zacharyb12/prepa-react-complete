# Commandes npm pour React

### Lancer l'application React

- les commandes sont situées dans le fichier package.json

- Il est possible d'ajouter des scripts personnalisés.

- Pour lancer l'application en mode développement, utiliser la commande :
  
```bash
  npm run dev
```
---

### Builder l'application


- Pour prévisualiser l'application construite, utiliser la commande :
  
```bash
  npm run preview
  ```

---

- Pour construire l'application pour la production, utiliser la commande :
  
```bash
  npm run build
```
---

### Autres commandes utiles

- Pour reinstaller les dépendances (après un changement de package ou une recuperation sur github), utiliser la commande :

```bash
  npm install
```
---

- Pour installer de nouvelles dépendances, utiliser la commande :

```bash
  npm install <nom-du-paquet>
```

---

- Pour désinstaller une dépendance, utiliser la commande :
  
```bash
  npm uninstall <nom-du-paquet>
```

---

- Pour mettre à jour les dépendances, utiliser la commande :
  
```bash
    npm update
```

---
