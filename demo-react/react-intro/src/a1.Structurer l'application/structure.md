# Structurer l'application

#### Composant principal
- `src/App.tsx` : composant principal de l'application.

#### Fichier CSS global
- `src/index.css` : fichier CSS global.

#### Point d'entrée HTML
- `index.html` : fichier HTML principal de l'application.

---

## Composants supplémentaires

- Nous allons créer tout au long du cours plusieurs composants React.

- il est conseillé de les organiser dans un dossier et des sous-dossiers selon leur fonctionnalité.

- Par exemple, créer un dossier `components` dans `src` pour y placer tous les composants réutilisables.

## Conventions de la structure
- `src/components/` : dossier pour les composants réutilisables.
- `src/pages/` : dossier pour les composants de pages.
- `src/assets/` : dossier pour les images, icônes, et autres ressources statiques.
- `src/utils/` : dossier pour les fonctions utilitaires et helpers.
- `src/hooks/` : dossier pour les hooks personnalisés.
- `src/styles/` : dossier pour les fichiers CSS ou SASS spécifiques.

---

## Le plus important sera de garder une structure claire et organisée pour faciliter la maintenance et l'évolution de l'application React. 


- Nous commencerons avec une structure simple et l'adapterons au fur et à mesure que l'application grandira en complexité.

- un dossier components

- un dossier pages
